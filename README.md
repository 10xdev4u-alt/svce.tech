# svce.tech — SVCE Tech Hub

A community hub for discovering tech events, clubs, and opportunities around **Sri Venkateswara
College of Engineering (SVCE), Sriperumbudur**.

Built on a simple, durable idea: **content lives in JSON files, anyone can contribute, and the site
survives every graduating batch.**

## ✨ Features

- 📅 **Events** — this month & upcoming, campus and nearby tech events
- 🏛️ **Clubs** — searchable directory of SVCE student chapters
- 💼 **Opportunities** — internships, hackathons, jobs, research (community-shared)
- 📚 **Resources** — off-campus portals, DSA/interview prep, courses (community-shared)
- 🌗 **Dark mode + mobile nav** — light-by-default theme with manual toggle, hamburger menu
- 🤝 **Contribute in 2 minutes** — edit a JSON file, open a PR

## 🛠️ Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router) · [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) + Framer Motion
- [Phosphor Icons](https://phosphoricons.com/)

## 🚀 Getting Started

```bash
pnpm install
pnpm dev
```

Visit `http://localhost:3000`.
